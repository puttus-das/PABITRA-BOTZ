# PABITRA-BOT V50 Website

The website is bundled with the bot and served by the same Express app. Deploy the **repository root** to Heroku; do not set `website/` as the Heroku root directory. The home page is available at `/`, the JSON health endpoint at `/health`, and pairing codes are generated by `/pair/:number` on the same origin.

The existing images and MP4 files remain under `website/assets/` and are served as static files, so the page's menu video and song videos remain available on Heroku. No separate Vercel deploy or API URL is required. If you later host this website on a different domain, set `WEBSITE_URL` on the backend and `window.PABITRA_API_URL` in `config.js` to the backend origin.

Set the required bot environment variables in the Heroku dashboard, including `BOT_TOKEN_TELEGRAM` and `TG_GROUP_ID` if Telegram is enabled. The website/API runs on the same dyno, so its URL serves both the page and pairing requests.

The Telegram `/pair +country-code-number` command remains available. On the website, enter a country-code number using digits only; then open WhatsApp → Linked Devices → Link a Device → Link with phone number instead and enter the returned code. Never share a pairing code.
